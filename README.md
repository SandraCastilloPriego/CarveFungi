# CarveFungi

CarveFungi reconstructs a fungal metabolic model from EggNOG functional annotations and a protein FASTA file. The workflow combines:

- reaction scoring from EggNOG annotations,
- compartment prediction from protein sequences,
- CarveMe model reconstruction,
- merging of constrained and open-bound models,
- SBML annotation and export.

The pipeline entry point is:

- `bin/CreateMetabolicModel.py`

---

## Requirements

This project expects a Python environment with the scientific packages used by the pipeline.

### Core Python

- Python 3.9+
- pip

### Required packages

Install the following packages before running the workflow:

```bash
pip install pandas numpy cobra libsbml biopython tensorflow
```

## Input files

The script requires three positional inputs:

1. `fungi_id`
   - a short identifier for the organism/model,
   - for example: `Saccharomyces_cerevisiae_S288C`

2. `eggnog_file`
   - the EggNOG functional annotation file,
   - usually an `.annotations` or similar output file generated by eggNOG-mapper.

3. `fasta_file`
   - the FASTA file containing the protein sequences for the organism.

### Example

```bash
python3 bin/CreateMetabolicModel.py \
  Saccharomyces_cerevisiae_S288C \
  data/annotations/functional/annotations.emapper.annotations \
  data/annotations/fasta/Saccharomyces_cerevisiae_S288C.faa
```

If the files do not exist, the script will stop and print a clear error telling you which file is missing.

## How to run it

From the project root:

```bash
cd /path/to/CarveFungi
python3 bin/CreateMetabolicModel.py <fungi_id> <eggnog_file> <fasta_file>
```

To see the help text:

```bash
python3 bin/CreateMetabolicModel.py --help
```

## Expected behavior

The pipeline performs the following steps:

1. Validates CLI arguments.
2. Loads the required scientific dependencies.
3. Runs compartment prediction on the input FASTA.
4. Reads EggNOG-based EC and gene annotations.
5. Assigns reaction scores from the universal reaction database.
6. Reconstructs models with CarveMe using both constrained and open-bound settings.
7. Merges the model ensembles.
8. Adds gene-reaction rules and external annotations.
9. Writes a final SBML model to the `results/` directory.

---

## Expected outputs

The workflow writes outputs under `results/`.

### Main output

- `results/<fungi_id>-<objective>.sbml`
  - final annotated model written in SBML format.
  - contains reaction and metabolite annotations plus model metadata.

### Intermediate outputs

The pipeline may also generate or clean up a number of temporary files, including:

- model files such as `...M.sbml` and `...O.sbml`
- compartment prediction files such as `*.loc_pred`
- score outputs such as `*_GeneEc.npy`
- temporary merged model files used during assembly

The code also removes intermediate files after the final model is generated, so the user typically ends with the final annotated SBML output in `results/`.
